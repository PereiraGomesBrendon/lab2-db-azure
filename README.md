# 💻 Azure Lab - Criação de Máquina Virtual e Banco de Dados SQL

Este projeto demonstra como criar recursos essenciais no Microsoft Azure, como Máquinas Virtuais (VMs) e Bancos de Dados SQL, usando a interface gráfica do portal Azure.

---

## 🖥️ Etapa 1: Criando uma Máquina Virtual

### Configurações principais:

- **Assinatura:** Assinatura de Plataformas MSDN  
- **Grupo de recursos:** Novo grupo para organizar os recursos
- **Região:** East US  
- **Zona de Disponibilidade:** Zona 1  
- **Segurança:** Inicialização confiável  
- **Imagem do SO:** Selecionável no processo (ex: Windows, Ubuntu)

### Monitoramento:

- Diagnóstico de inicialização habilitado (armazenamento gerenciado)
- Possibilidade de ativar alertas e diagnóstico de integridade

---

## 🗄️ Etapa 2: Criando um Banco de Dados SQL

### Configurações principais:

- **Nome do banco:** `testetestesql`
- **Servidor:** Criação de um novo servidor lógico
- **Pool elástico:** Não utilizado neste exemplo
- **Ambiente:** Desenvolvimento

---

## 📌 Considerações Finais

- **Alta disponibilidade:** Uso de zonas de disponibilidade melhora a resiliência.
- **Imagens oferecidas:** O Azure oferece diversas opções de sistemas operacionais.
- **Custos e escalabilidade:** Escolhas como ambiente e região impactam o custo.
